# ナブラ演算子ゲーム（CPU 対戦版）

微分・積分・極限・逆関数を使って、相手の場の基底を消していくカードゲームです。
東京大学の学生が考案したカードゲーム「[ナブラ演算子ゲーム](https://nablagame.com/)」の公式ルールをもとに、ブラウザで CPU と対戦できるようにした**非公式のファンメイド版**です。

## 遊び方

最初のメニューで **CPU と対戦** か **インターネット対戦** を選べます。インターネット対戦は「部屋を作る」で出た 5 文字の部屋コードを相手に伝え、相手が「部屋に入る」で入力すると始まります（WebRTC / PeerJS を使ったブラウザ同士の直接通信。GitHub Pages など公開した版で動きます）。

`index.html` をブラウザで開くだけで遊べます。ビルドもインストールも不要です。

3D のテーブルの上で、手札のカードを場の基底へ**ドラッグ＆ドロップ**して出します（タップで選んでから基底をタップしてもOK）。カードを別のカードに重ねると、d/dx の複数回や「× と関数」のようなコンボになります。

### 基本ルール

- お互いの場には最初に基底 `1, x, x²` が置かれています。基底の数がその場の「次元」です。
- 手札は 7 枚。1 ターンに 1 回だけ操作をして、使った枚数だけ山札から補充します。
- 操作は自分の場にも相手の場にも使えます。
- 基底は **0 になる**、**±∞ に発散する**、**他の基底と線形従属になる** と消えます。
- 相手の場を 0 次元にしたら勝ちです。山札が尽きたら、次元の大きいほうが勝ちます。

### カード

| 種類 | カード | 効果 |
|---|---|---|
| 関数 | 0, 1, x, x², sin x, cos x, eˣ | 場に追加する（0 は × と組み合わせる） |
| 微積分 | d/dx, ∫ | 基底 1 つを微分・積分する（重ねると複数回） |
| 微積分 | ∇, Δ | 片方の場の基底すべてを 1 回・2 回微分する |
| 代数 | ×, ÷ | 関数カードと組み合わせて掛ける・割る |
| 代数 | √, log, f⁻¹ | 平方根・自然対数・逆関数 |
| 極限 | x→+∞, x→−∞, x→0, liminf, limsup | 有限値なら定数関数に、±∞ なら消滅 |

## ファイル構成

```
index.html      画面
css/style.css   見た目（ライト／ダーク両対応）
js/engine.js    数式エンジン（有理数、微分、積分、逆関数、極限、線形従属の判定）
js/game.js      ルール、山札、CPU の思考
js/ui.js        画面操作、アニメーション、エフェクト、インターネット対戦
js/peerjs.min.js インターネット対戦用の通信ライブラリ（PeerJS）
```

## GitHub Pages で公開する

1. このフォルダの中身をリポジトリに push する
2. リポジトリの **Settings → Pages** を開く
3. **Branch** で `main` と `/ (root)` を選んで保存する

数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で遊べるようになります。

## 公式版との違い

- カードの枚数は既存の Web 移植版を参考にしたもので、実物と違う可能性があります。
- 公式では反則をすると負けですが、この版では反則になる操作は出せないようにしています。
- 式で表せない積分や逆関数（x eˣ の逆関数など）は使えません。
- 極限は数値計算で判定しています。
